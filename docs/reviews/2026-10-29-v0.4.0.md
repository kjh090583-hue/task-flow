## 확인하지 못한 것

- **실제 Claude API 로 받은 제안**: 키가 거절되어 확인하지 못했다. 가짜 서버의 값(높음 · 내일)이 화면에 맞게 들어가는 것까지만 확인했다.
- **migrated@test.com 계정**: 실제 DB 를 열지 않아 이 계정으로는 지나가지 않았다.
- **사람의 눈**: 화면은 자동 조작으로 읽었다.
- **좁은 폭에서의 시나리오 일곱 줄**: 1280 에서만 돌렸다.
- **다크 모드, 실제 휴대폰, PR #34(AI 로 할 일 만들기)**: 확인하지 않았다. #34 는 병합하지 않았다.
